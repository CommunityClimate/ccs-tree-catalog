📖 CCS Active Tree Catalog — User Handbook
1 — Getting Started
Connecting to Fieldforce (Live Data)
Click the ☁ Connect to Fieldforce button in the left sidebar. You will be prompted to sign in with your Microsoft account. Once authenticated, the system automatically loads all Active Fields and Active Trees from Dataverse — no file needed.
Fields load immediately. Trees load in pages of 5,000 and the button shows progress (page 6 of 20…). Wait until loading completes before running allocation.
Using Excel Export (Offline Fallback)
If Fieldforce is unavailable, export Active Fields and Active Trees from Dynamics/Fieldforce as .xlsx files. Drop each file into the corresponding upload zone. Column names are detected automatically.
Running Allocation
1
Upload or connect both Active Fields and Active Trees
2
Click ▶ Run Allocation — a progress bar shows processing status
3
When complete, all KPIs update in the header and the catalog populates
💡 With 500k+ trees, allocation takes 30–60 seconds. The progress bar shows live counts as it runs.

3 — Tree Catalog Tab
The catalog shows all trees in a searchable, sortable table. Use the search bar to find any tree by code, species, field ID, or owner name.
Filters (left sidebar)
Filter by Status, Field ID, Field Owner, Species, or Zone. Filters combine — e.g. Status=Mismatch + Zone=Mpulungu shows only mismatched trees in that zone. Click Clear Filters to reset.
Clicking Field IDs
Both the Tree Field and Matched Field columns are clickable links (dotted underline). Clicking any field ID switches to the Field Map tab and centres the map on that field polygon with all its trees shown.
Sorting
Click any column header to sort. Click again to reverse. The Sort: Status and Sort: Field buttons at the top right are quick shortcuts.
💡 The catalog paginates at 100 rows. Use the ← Prev / Next → buttons at the bottom to navigate pages.
4 — Field Map Tab
The map shows a satellite view of a selected field polygon with all its associated trees plotted as numbered circles.
Selecting a Field
Click any field in the Fields list in the left sidebar, or click a field ID link in the catalog table. The map switches automatically and centres on the polygon.
Map Markers
MarkerMeaning
● Green numberedTree allocated inside this polygon
● Red numberedTree outside this polygon boundary
● Amber numberedTree inside but field/owner mismatch
● Blue dashed outlineField polygon boundary
Click any marker on the map to see a popup with the tree code, status, coordinates, and matched field.
Measurement Tools
📐 Side lengths — labels every polygon side with its length in metres. Green = within 15% of 20m target, red = more than 30% off. A summary shows average side and total perimeter.
📏 A→B Ruler — click to place point A, click again for point B. A distance label appears. Drag either handle to measure any distance on the map.
💡 The field summary panel (top right of map) shows inside count, outside count, and mismatch count for the selected field.
5 — Exceptions Tab
The Exceptions tab shows all trees that require attention. It is built on demand when you first click the tab — with large datasets this takes a few seconds.
Exception Cards
Four summary cards show counts for each exception type. Click any card to filter the exceptions table below to just that category. Click again to clear the filter.
Mismatch Breakdown Panel
Below the cards, the breakdown panel diagnoses why mismatches are occurring across three categories:
Blank Tree Field — the tree record has no Field value, so the system assigned the nearest polygon. Not a real error — a data entry gap in Fieldforce.
Genuine Field Conflict — the tree record says Field A but the GPS lands in Field B. Requires investigation.
Field Tagged but No Spatial Match — tree has a field tag but lands outside all polygons. Likely a GPS or polygon boundary issue.
💡 The exceptions table shows the first 500 rows. Use ⬇ Export CSV to download the full exception list.
6 — Understanding Mismatches
A mismatch means a tree was found spatially inside a field polygon, but the tree's own record says it belongs to a different field.
Two common causes
1. Overlapping or misplaced polygons — when field boundaries are drawn too close together or are in the wrong location, a tree planted in Field A can accidentally land inside Field B's polygon. The system flags it as a mismatch because the tree record says "Field A" but the geometry says "Field B". This is a polygon problem, not a tree problem.
2. Missing field tag — some trees were submitted to Fieldforce without a Field ID recorded. The system assigns the nearest polygon spatially but flags the result because it cannot confirm the assignment. This is a data entry gap — fixable by ensuring field officers select the Field when recording trees.
⚠ A mismatch is not necessarily a mistake by the farmer or field officer. In most cases it indicates a polygon boundary that needs correction in the Polygon Corrector tool.
Suspect Fields Panel
Below the Mismatch Breakdown, the Suspect Fields panel lists all fields where a high percentage of trees are mismatched. Use the threshold slider to set the sensitivity (default 80%). Fields at 100% mismatch rate almost always have a misplaced polygon boundary.
7 — Excluding Problem Fields
Fields with misplaced polygon boundaries can be temporarily excluded from the allocation results so they do not distort the overall numbers while corrections are being made.
How to exclude a field
1
Go to the Exceptions tab
2
In the Suspect Fields panel, set the threshold slider (e.g. 80%)
3
Click Exclude on individual fields, or click ✕ Exclude all shown
4
All KPIs and the catalog update instantly — excluded trees are reclassified as Outside
5
A red banner shows how many fields and trees are excluded
You can also type a Field ID directly in the Excluded Polygons box in the left sidebar and press Enter to add it manually.
💡 Exclusions only affect this session. The underlying data is not changed. Once a polygon is corrected in the Polygon Corrector, re-run the allocation and remove the exclusion.
Fixing excluded fields
Take the Field ID to the CCS Polygon Corrector tool, redraw the boundary to the correct location, and save the corrected GeoJSON back to Fieldforce/Dataverse.
8 — Exporting & Reports
⬇ Export CSV
Downloads all allocation results as a .csv file including tree code, species, coordinates, field assignment, match flags, and status. The full dataset is exported — not just the 100 rows visible on screen.
☁ Save to Fieldforce
Writes the allocation results back to Dataverse, updating each tree record with its matched field ID and allocation status. Requires an active Fieldforce connection.
📋 Compliance Report
Generates a multi-section PDF report suitable for Verra/Gold Standard certification review. Sections include Allocation Overview, Species Breakdown, Field Summary, Exceptions List, and Polygon Quality. Select which sections to include before downloading.
💡 Always exclude known problem fields before generating a Compliance Report so the numbers reflect only verified, correctly allocated trees.
